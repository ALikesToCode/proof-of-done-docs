# Documentation and support for Proof of Done

This repository holds the public pages for Proof of Done, an app for Jira Cloud. The app gives a work item a done contract and reports it as proven when every criterion has accepted evidence.

- [Get started](https://alikestocode.github.io/proof-of-done-docs/)
- [Reference](https://alikestocode.github.io/proof-of-done-docs/reference/)
- [Coding agents](https://alikestocode.github.io/proof-of-done-docs/agents/)
- [Support](https://alikestocode.github.io/proof-of-done-docs/support/)
- [Privacy policy](https://alikestocode.github.io/proof-of-done-docs/privacy/)
- [Terms of use](https://alikestocode.github.io/proof-of-done-docs/terms/)

To report a problem with the app or a mistake in these pages, [open an issue](https://github.com/ALikesToCode/proof-of-done-docs/issues/new/choose). To report a vulnerability, read [SECURITY.md](SECURITY.md).

The code of the app is not in this repository.
