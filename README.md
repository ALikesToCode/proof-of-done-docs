# Proof of Done: documentation and support

This repository holds the public pages for Proof of Done, an app for Jira Cloud. The app gives a work item a done contract and counts it as done only when each criterion has evidence that someone else accepted.

- [Documentation](https://alikestocode.github.io/proof-of-done-docs/)
- [Support](https://alikestocode.github.io/proof-of-done-docs/support/)
- [Privacy policy](https://alikestocode.github.io/proof-of-done-docs/privacy/)
- [Terms of use](https://alikestocode.github.io/proof-of-done-docs/terms/)

To report a problem with the app, [open an issue](https://github.com/ALikesToCode/proof-of-done-docs/issues/new/choose). To report a vulnerability, read [SECURITY.md](SECURITY.md).
